# 🏛️ Wealth Command Center

## 🚀 The Financial Growth Funnel
This application is the final stage of a strategic 3-step financial lead-generation funnel:
1. **Financial Reality Check** $\rightarrow$ The "Wake-up Call" (Psychological trigger).
2. **Control Your Finances** $\rightarrow$ The "Fix" (Budgeting and management).
3. **Wealth Command Center** $\rightarrow$ The "Growth" (Real-time market intelligence & investing).

## 🛠️ Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS v4 (Terminal UI)
- **Data Fetching:** SWR (Stale-While-Revalidate)
- **Visualization:** Chart.js / Lightweight Charts
- **APIs:** Finnhub (Stocks), CoinMarketCap (Crypto), GNews (Intelligence)
